# Editor Immagini Online

Editor per ritagliare, ruotare e modificare immagini direttamente dal browser. Nessuna installazione richiesta, tutto viene elaborato localmente nel tuo browser per la massima privacy.

## Caratteristiche

- **Caricamento**: Carica immagini tramite selezione file o drag & drop
- **Area di lavoro ampia**: L'immagine viene mostrata dentro un grande riquadro bianco che occupa tutta la larghezza disponibile, con spazio per zoomare e posizionare l'immagine
- **Spostamento dell'immagine**: Trascina l'immagine all'interno dell'area di lavoro per posizionare al meglio la porzione che ti interessa, anche dopo aver applicato lo zoom
- **Ritaglio personalizzato**: Riquadro di ritaglio tratteggiato, trascinabile e ridimensionabile con 8 maniglie, che può essere posizionato su tutta l'area di lavoro
- **Dimensioni preset**:
  - Fototessera (314×251 px)
  - Firma (50×251 px)
  - Dimensioni personalizzate
- **Rotazione**:
  - Rotazione rapida a 90° e -90°
  - Rotazione precisa con ruota interattiva per regolazioni di qualsiasi grado
- **Specchiatura**: Flip orizzontale e verticale
- **Zoom**: Regolazione da 10% a 300%, centrato sul riquadro di ritaglio (la zona che stai inquadrando resta ferma mentre ingrandisci)
- **Filtro bianco e nero**: Conversione istantanea in scala di grigi
- **Controllo dimensione file**: Il file esportato viene compresso automaticamente entro 30 KB (valore fisso)
- **Esportazione**: Salva in formato JPG a 200 DPI (dimensione massima 33×40 mm, circa 259×314 px). Il file contiene esattamente ciò che vedi nel riquadro di ritaglio, compreso lo spostamento dell'immagine

## 🚀 Utilizzo

1. Apri l'editor nel browser
2. Carica un'immagine (clicca "Scegli File" o trascina l'immagine nell'area centrale)
3. Applica le modifiche desiderate:
   - Seleziona o personalizza le dimensioni di ritaglio
   - Regola lo zoom con lo slider
   - **Trascina l'immagine** (fuori dal riquadro tratteggiato) per spostarla
   - **Trascina il riquadro tratteggiato** per posizionare il ritaglio, oppure usa le maniglie per ridimensionarlo
   - Ruota l'immagine
   - Specchia orizzontalmente o verticalmente
   - Applica il filtro bianco e nero se necessario
4. Esporta l'immagine in JPG con il pulsante "💾 JPG"

## 🖱️ Come muovere immagine e ritaglio

| Azione | Risultato |
| --- | --- |
| Trascinare l'immagine (fuori dal riquadro tratteggiato) | Sposta l'immagine nell'area di lavoro |
| Trascinare dentro il riquadro tratteggiato | Sposta il riquadro di ritaglio |
| Trascinare le maniglie del riquadro | Ridimensiona il ritaglio |
| Slider Zoom | Ingrandisce/riduce l'immagine attorno al centro del riquadro di ritaglio |

## 🔒 Privacy

Tutte le operazioni vengono eseguite localmente nel tuo browser. Le immagini non vengono mai caricate su server esterni. I tuoi dati rimangono sul tuo dispositivo.

## 💻 Tecnologie

- HTML5 Canvas per l'elaborazione delle immagini
- JavaScript vanilla (nessuna dipendenza esterna)
- Layout responsive; il trascinamento di immagine e ritaglio è gestito con il mouse (uso consigliato da desktop)
- Interfaccia drag & drop moderna
